PixelCore - NES

A Nintendo Entertainment System emulator built from scratch in C++ for Linux. One project in the growing PixelCore family.

AppImage

Recommended for most users. Download one file and run it. No Git, compiler, or development tools required.

DOWNLOAD FOR LINUX

After downloading, open a terminal in the download folder and run:

chmod +x PixelCore-NES-x86_64.AppImage
./PixelCore-NES-x86_64.AppImage

It includes the features from the published release. It does not include game ROMs; use your own legally obtained game files.

Build from source

Get the complete source code if you want to inspect, modify, or build PixelCore - NES yourself. This option requires Linux build tools and SDL2 development files.

1. Install the dependencies

sudo apt update
sudo apt install build-essential cmake pkg-config libsdl2-dev zenity

2. Download the source code

git clone https://github.com/kaz1071/PixelCore---NES.git
cd PixelCore---NES

3. Build and install

cmake -S . -B build -DCMAKE_INSTALL_PREFIX="$HOME/.local"
cmake --build build -j$(nproc)
ctest --test-dir build --output-on-failure
cmake --install build

To update a copy you already cloned later, run git pull from inside the PixelCore---NES folder, then repeat the build commands.
