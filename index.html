PixelCore - NES

A Nintendo Entertainment System emulator built from scratch in C++ for Linux. One project in the growing PixelCore family.

Get PixelCore - NES

On Debian or Chromebook Linux, open Terminal and paste this command. It installs the build tools, downloads the source, builds the emulator, and adds it to your app launcher.

sudo apt update
sudo apt install -y git build-essential cmake pkg-config libsdl2-dev zenity
git clone https://github.com/kaz1071/PixelCore---NES.git
cd PixelCore---NES
cmake -S . -B build -DCMAKE_INSTALL_PREFIX="$HOME/.local"
cmake --build build -j$(nproc)
cmake --install build
