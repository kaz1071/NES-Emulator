Download AppImage

Get the ready-to-run Linux version of PixelCore - NES. This is the easiest option for most people and does not require Git or development tools.

1. Download the AppImage

Download the latest published build:

DOWNLOAD FOR LINUX

2. Make it executable and run it

Open a terminal in the folder where the file was downloaded, then run:

chmod +x PixelCore-NES-x86_64.AppImage
./PixelCore-NES-x86_64.AppImage

If your desktop asks whether to run the file, choose Run.

The AppImage contains the features included in that published release. It does not include game ROMs; use your own legally obtained game files.
