Build from source

Download the complete source code if you want to inspect, modify, or build PixelCore - NES yourself. This requires Linux build tools and SDL2 development files.

1. Install dependencies

sudo apt update
sudo apt install build-essential cmake pkg-config libsdl2-dev zenity

2. Clone the repository

git clone https://github.com/kaz1071/PixelCore---NES.git
cd PixelCore---NES

3. Build and test

cmake -S . -B build -DCMAKE_INSTALL_PREFIX="$HOME/.local"
cmake --build build -j$(nproc)
ctest --test-dir build --output-on-failure
cmake --install build

After installation, launch PixelCore - NES from your Linux app launcher, or run:

~/.local/bin/nes-emulator

Updating later

If you already cloned the repository, open a terminal inside the PixelCore---NES folder and run:

git pull
cmake --build build -j$(nproc)
ctest --test-dir build --output-on-failure
cmake --install build

This gives you the complete source code and lets you make your own changes. It does not automatically provide extra emulator features; those depend on the code and build configuration.
